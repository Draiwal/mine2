# GTA Combat 2.0 (Forge 1.20.1)

## Сборка .jar через GitHub
1. Создай репозиторий на github.com, загрузи СОДЕРЖИМОЕ этой папки (src, tools, build.gradle, .github ...).
2. Вкладка Actions -> Build mod -> зелёная галочка -> Artifacts -> gtacombat-jar.
3. .jar в папку mods (Minecraft 1.20.1 + Forge 47.x).

## Управление
ПКМ (удерживать) - прицел | ЛКМ - огонь | R - перезарядка | Z (удерживать) - колесо оружия
G - установить обвес из левой руки, Shift+G - снять все обвесы | V - сменить скин оружия
Все клавиши меняются в настройках управления (категория GTA Combat).

## Что внутри
- 6 стволов с 3D-моделями, 4 скина, 4 обвеса (глушитель, расш. магазин, оптика, рукоять) - всё видно на модели
- Свои звуки (синтез), хитмаркеры со звуками, вспышка, гильзы, тряска камеры
- Камера из-за плеча, пуля летит точно в прицел
- Руки на оружии, анимации доставания/бега/отдачи/перезарядки
- Рецепты крафта, конфиги (config/gtacombat-client.toml, serverconfig/gtacombat-server.toml)

## Перегенерация ассетов
`python3 tools/generate_assets.py` (Pillow, numpy, scipy, ffmpeg c libvorbis) - можно править дизайн
оружия, цвета скинов и параметры звуков в самом скрипте.
